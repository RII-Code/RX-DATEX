# RX-PSU-MONITOR (Power Supply)

Modul power supply AC-DC yang dilengkapi monitoring realtime untuk kebutuhan embedded system, IoT, dan industrial device.

## Fitur

- AC to DC converter (output: 5V 10W)
- Monitoring realtime
- I2C communication
- Low power monitoring
- Compact PCB design
- Industrial ready
- Overcurrent monitoring
- Voltage sensing
